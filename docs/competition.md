# 比赛对标与亮点叙事

> 这份文档只回答一个问题：Hiro2 距离比赛要求还有多远、凭什么赢。
> 评分权重与产品取向见 [`product.md`](product.md)；指标口径与评测对象见 [`evaluation.md`](evaluation.md)；市场差异依据见 [`research/market-fit.md`](research/market-fit.md)。
> 本文档数字只能来自可复现产物（`evaluation_runs`、`metrics.json`、覆盖率报告），禁止手工填写；状态随评测运行更新。

## 结论

基本盘闭环已通：多源数据到匹配的同一条链路在后端成立，17 个岗位版本已发布（12 个岗位，5 个升版 v3），180 条冻结评测集（role 100 + domain 50 + event 30，哈希锁定）与 78% 覆盖率两项硬指标达标。

三项硬指标全部达线：97% / 98% / 100%（评测集 eval-v3，标注链 ai-prelabel-batch 预标注 → ai-cross-review 逐条证据交叉复核 → gold 锚定，身份全程透明）；创新性素材（四层时间轴、五年快照对比、防幻觉机制、三层飞轮）独家但分散，待提交文档收纳呈现。剩余缺口仅在提交材料（PPT/视频/案例包）。

评测闭环为：`evalset.py freeze`（冻结分层样本，带哈希）-> 审核任务标注（`/tasks` 页，AI 预标注建议 + 人工确认）-> `evalset.py score`（确定性计算）。**gold 锚定机制（2026-09-01）**：49 条岗位映射 case 经逐条职责证据裁决锚定（`reviewer_id=ai-cross-review` + `corrected_payload`，含 16 条显式 None 锚定=目录外），锚定优先级高于一切自动判定（repair 治理链：锚定 > 继承 semantic > 规则 + 重判）；锚定的语义依据与双方 AI 意见对照见 `evaluation/samples/lock-list.json` 与提交对话记录。三层与官方口径对应：岗位映射↔JD 解析、领域判定↔简历提取（is_ai_role 判定）、事件抽取↔人岗匹配（抽取要素准确性）。

## 评分项对标

### 完整性 30

要求：多源数据到匹配的同一条闭环；新岗位和既有岗位案例。

- 已贯通：来源登记 -> 五道质量门 -> 新岗位候选（五路证据）-> 双时间窗对比（13 项变化带证据）-> 审核留痕 -> 不可变发布（17 版本）-> 匹配报告（21 候选人）-> 学练赛证学习路径。`job_version_id` 在后端贯通。
- 差距：求职区前端闭环已补齐（五页：首页/目标岗位/我的画像/候选诊断/学习路径，端到端测试覆盖），但诊断页仍复用招聘语境表述，求职语境优化待做。
- 动作：诊断页文案与信息架构按求职者视角优化（非页面新建）。

### 创新性 25

要求：去重、时效、交叉验证、幻觉拦截的前后对比。

| 素材 | 事实 |
| --- | --- |
| 四层时间传导轴 | 论文 -> 开源包生态（PyPI/npm） -> 日报 -> 招聘需求（JD）实证传导 5~7 年（大模型应用 70 个月；Prompt 工程 26 个月为实践先于学术的反例）；中美对照（美国 O*NET 2005-2025 + 中国职业大典 2015 -> 2022 -> 动态新增 76 职业） |
| 五年快照对比引擎 | Wayback 历史池对比现行池，16 岗位 139 项变化，与手工五年对比方向一致 |
| 防幻觉机制 | 预测侧双重时间截止闸门：回测时信号数据与技能词典各自只使用截止日当时已可用的版本，防止“用今天的知识解释过去”的时间穿越；删除项证据不足标“待确认”；预测只产出岗位影响建议，不触碰岗位版本 |
| 词典演进 | v4 -> v5 命中率 27.4% -> 25.6% -> 30.8%，含撤回 10 个错配词的纠错记录；**词表新词闭环已建**（aliasprobe，2026-09-01）：unmatched JD n-gram 聚类 + 日报技能突增双信源 -> 提议 agent 查证 -> 人审生效。首次运行 410 候选 -> 15 查证（12 新岗信号含 FDE 簇、与涌现扫描互相印证；2 噪声弃用），词表从静态先验变为数据驱动资产 |

- 差距：证据散在 `/temporal/*` 五个无主导航入口的子页和 CHANGELOG 中，无一屏可读的"前后对比"。
- 动作：按 [`design-data.md`](design-data.md) 收纳至评测与质量页，对比叙事集中呈现。
