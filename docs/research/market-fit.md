# 市场与发榜方契合度

> 调研目的：明确 Hiro2 不是招聘平台的复刻，而是面向 AI 产业人才供需的可信岗位能力标准系统。
> 资料原则：优先使用发榜方、猎聘和 BOSS 直聘的官方页面、官方年报或投资者关系材料。
> 更新日期：2026-08-24。

## 结论

猎聘和 BOSS 直聘的核心目标是提升“找人、筛人、沟通、邀约、面试和成交”的效率；Hiro2 不应在海量人才库、职位流量、即时沟通或招聘交付上竞争。

Hiro2 的差异应放在：

```text
技术与产业信号
-> 可验证的岗位能力变化
-> 人工确认的岗位版本
-> 青年能力诊断与培养反馈
```

它服务招聘，但更靠近“岗位能力标准建设、AI 人才培养和动态供需反馈”。

## 发榜方方向

科大讯飞的 2025 年报描述了智能体平台在知识库、会议纪要、员工培训等场景的规模化部署，也提出“学练赛证”一体化的大模型人才培养体系，并提及 AI 大模型应用工程师证书及生成式 AI 相关职业标准。<https://static.cninfo.com.cn/finalpage/2026-04-29/1225233581.PDF>

讯飞星辰 Agent 平台强调 Prompt、工作流和自主智能体，以及 RAG、工具、效果测评、微调和全链路闭环优化。<https://www.xfyun.cn/doc/spark/Agent01-%E5%B9%B3%E5%8F%B0%E4%BB%8B%E7%BB%8D.html>

这意味着 Hiro2 应强调以下能力：

| 发榜方方向 | Hiro2 对应设计 |
| --- | --- |
| 垂类智能体与企业应用 | 岗位能力版本作为企业可复用标准 |
| 效果测评与闭环优化 | JD、简历、匹配、预测的冻结评测与人工复核 |
| AI 人才培养 | 学练赛证式能力提升路径和培养任务 |
| 开放生态与多模型 | Provider Adapter，不锁定单一模型 |
| 合规开发 | 简历授权/脱敏、证据可追溯、辅助决策边界 |

## 同行能力

### 猎聘

猎聘定位为中高端人才招聘平台，基于人才库、猎头网络和招聘 SaaS 提供职位发布、人才搜索、简历解析、AI 推荐、邀约、面试和背调等招聘闭环。其官方材料还强调人岗语义匹配、行为反馈和多因子排序。<https://ir.liepin.com/product/> <https://ir.liepin.com/system/>

| 已有强项 | Hiro2 不应复刻 |
| --- | --- |
| 大规模人才库与人才搜索 | 候选人流量和简历海筛 |
| 招聘沟通、邀约和面试 | IM、电话、批量邀约和面试流程 |
| 猎头协作和背景调查 | 招聘交付与交易闭环 |
| 推荐排序与意向识别 | 平台内转化率优化 |

### BOSS 直聘

BOSS 直聘官方招聘入口强调招聘者与求职者直接沟通，以及提升人才匹配效率；其 2025 ESG 报告也说明以 AI 与大数据降低无效面试和重复投递。<https://www.zhipin.com/zhaopin/> <https://ir.zhipin.com/system/files-encrypted/nasdaq_kms/assets/2026/04/29/9-28-11/2025%20Annual%20ESG%20Report%20%28CN%29.pdf>

| 已有强项 | Hiro2 不应复刻 |
| --- | --- |
| 职位和人才即时撮合 | 即时聊天、投递和平台流量 |
| 平台内匹配效率 | 面向点击、回复和面试转化的排序 |
| 海量职位供给 | 通用岗位搜索和职位分发 |

## Hiro2 差异化

| 维度 | 猎聘/BOSS 直聘 | Hiro2 |
| --- | --- | --- |
| 主要问题 | 如何更快找到并转化候选人 | 岗位能力标准如何随产业变化而可信更新 |
| 数据核心 | 人才库、职位库、行为与沟通数据 | JD、职业标准、专家矩阵、技术/产业信号、证据链 |
| 岗位定义 | 招聘需求输入和职位画像 | 版本化、可审核、可回溯的岗位能力标准 |
| AI 输出 | 推荐、筛选、邀约、面试辅助 | 新岗位候选、岗位变化建议、证据和能力差距 |
| 时间能力 | 侧重当前撮合与行为反馈 | 历史回测、变化证据、趋势建议与版本演化 |
| 人才侧价值 | 职位推荐和求职辅助 | 基于已发布岗位版本的能力诊断和学练赛证路径 |
| 合规边界 | 招聘平台流程与用户交易 | 不自动淘汰或录用，只提供能力发展建议 |

## 产品取舍

### 必须做

```text
新岗位候选与定义
既有岗位新增/删除/修改
技术栈、职级、技能点图谱
技能输入与 PDF/DOCX 简历诊断
证据、人工优化、版本发布
100+ JD 与三项准确率评测
```

### 作为可信性支撑

```text
日报/RSS 信号
历史回测
未来趋势建议
预测复盘
```

### 不做

```text
人才库
职位发布市场
即时聊天与批量邀约
猎头网络
自动淘汰或自动录用
通用新闻阅读器
```

## 更契合发榜方的能力模型

岗位能力不应只是工具名称集合，而应遵循 AI 应用工程能力链：

```text
需求与场景理解
-> 数据与知识处理
-> 智能体与工作流构建
-> 工具与系统集成
-> 效果评测与迭代
-> 部署、运营与治理
```

MCP、RAG、LangGraph、向量数据库等是能力域下的技能点。这样既能表达技术变化，也能承接企业培养、实践任务和能力证明。

## 答辩表述

> 猎聘和 BOSS 直聘解决“如何更高效地完成当前招聘撮合”；Hiro2 聚焦“企业当前应该招什么样的人，以及青年应如何形成这些能力”。系统以多源证据和人工审核将产业变化沉淀为版本化岗位标准，再将标准用于招聘、培养和个人发展诊断。

## 需要持续验证的问题

- AI Agent 工程师是否在所选时间窗内满足“新岗位候选”条件，而不是既有热门名称。
- 技术先导信号对 JD 变化是否具有可量化的提前量。
- 专家矩阵、JD 和技术信号冲突时，人工审核是否能形成稳定标准。
- 学练赛证路径能否被任务、项目证据和能力证明具体化，而不是停留在课程推荐。
